login design (both ruled deliberate by her, closed), a first-load weight problem, a batch

## Findings and her rulings

1. **Shop table grants** (fix queued). `schema.sql:319` revokes them, but a later migration
   re-created `shop_items` and the default grants returned. RLS still blocks rows: an anon
   REST probe returns `[]`. Lesson: recreating a table means re-running its revoke.
2. **Ten helpers executable by anon and authenticated** (fix queued). `_mhq_admin_ok`,
   `_mhq_auth`, `_mhq_ensure_blip`, `_mhq_health`, `_mhq_is_qual_day`, `_mhq_tray`,
   `_mhq_dice_xp`, `_mhq_growth`, `_mhq_level`, `exam_name_key`. Harmless today; same
   shape as the Circle Quest fix of 2026-08-15. `send-push` calls two of them with the
   service role, so that grant must stay explicit.
3. **First-login has no class code and passwords are 4+ characters, default bcrypt cost,
   no throttle.** Her ruling: deliberate, "I know my kids", not a security risk. CLOSED,
   never re-raise.
4. **XP and score are trusted from the phone** (accepted risk from the 6 Aug audit; a
   server clamp is queued; gold-on-pass is her call).
5. **`schema.sql` is not a standalone rebuild file** (mirror-back queued): three bodies
   drift from live (`mhq_admin_data`, `mhq_equip`, `mhq_exam_open_part`), seven functions
   exist only in migration files, and thirteen live only on the server (twelve `exam_*`
   for the sept 2024 check-in site, `keepalive` for the pinger; cleared 2026-08-26).
6. **First load is the whole app**: 307 files / 5.0 MB reachable from `js/app.js` before
   login, one dynamic import in the codebase, service worker network-first so every open
   re-validates every file. Lazy-load plan queued.
7. **Sprites are heavy**: 40 animation frames 11 MB, the companion folder 19.6 MB, loaded
   on demand. WebP conversion queued.
8. **Cleanup** (all queued): 1.2 GB of screenshot output in `tools/`; git never packed
   (3 155 loose objects); `art-source/` 96 files / 101 MB tracked in a public repo (her
   call, default leave); the neutralised `paper-seed` function; one test feedback note;
   docs still describing self-signup and eleven chapters (README line flagged 2026-08-06,
   still there); the project memory file at 80 KB; a past-due assignment still active.
9. **Pedagogy.** 12 of 20 accounts active in the week, 7 learners never finished a round,
   the assigned trig rounds reach 8 to 10 learners, every other round 2 or fewer, dice
   mode 2 completed plays, Exam Focus essentially unused. Her ruling: mid-exams, not
   pushing, not a big deal. CLOSED. The feedback box is one learner's channel, answered on
   WhatsApp; no reply field, never rebuild the app around one learner. CLOSED.
10. **Concept card gap** (fix queued): the exponential card teaches `y = a·bˣ + q` with no
    p while Fun Functions and the exam cards use the Grade 11 form; a learner's note pushed
    back on exactly this and the card agreed with her.
11. **Steepness is used but never defined** (one-line reminder queued, in graph-quest).
12. **Sick-Blip re-entry cost** (gentle return queued): 5 unfed weekdays and Blip refuses
    food, 7 and the shop locks; healing costs 35 gold a day for three weekdays. On audit
    day 11 of 20 Blips were sick and 8 locked. The admin Term toggle already pauses the
    clock for everyone.
13. **Learner request**: the outline should follow the body colour. Queued; her rulings:
    automatic outline, eyes follow.

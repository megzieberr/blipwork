Part 2 · the method rule — which skills get a “📖 Show me the method” link

DICE-COMMON's rule: attach q.method ONLY where the solution is real working (2+ steps, or a step with a reason, or a single step whose text is not just the answer). Everything else would be a spoiler button, so the link is simply omitted. This block pins that split by name, so a later edit cannot silently change it.

Part 3 · tolerances arrive intact through genAt

Many 2D-Trig calc skills carry a tuned tol (0,015 sine/cosine rounding drift · 0,1 for angles to 1 dp · 0,5 for the regular-polygon triangle method · 0,06 for the house composite). answerCorrect() reads them off the question object, so a tol lost on the way through the dice wrapper would silently start failing correct learner answers. Every calc skill's (dp, tol) signature set is collected from static play and from dice play and the two sets must be identical.
